# Repository artwork

The original SVG artwork in this directory is covered by the repository's MIT license. Agent names are identification labels; no third-party logos are embedded and no endorsement is implied.

- `prompt-optimizer-preview.svg`: editable 1280×640 banner.
- `prompt-optimizer-preview.png`: raster export for GitHub and social sharing.
- `architecture.svg`: scalable workflow diagram.

The PNG was rendered with `@resvg/resvg-js` 2.6.2 using Inter and Roboto Mono fonts from [Google Fonts](https://github.com/google/fonts), both distributed under the SIL Open Font License. Font binaries are not bundled; SVG text uses system fallbacks. To regenerate, render the SVG at its native dimensions with these fonts available.

Upload `prompt-optimizer-preview.png` in GitHub → Settings → General → Social preview. See [GitHub's upload instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
