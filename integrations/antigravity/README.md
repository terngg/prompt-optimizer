# antigravity integration

This template requires replacing the absolute build path. Prefer `node scripts/config.mjs antigravity` from the repository root to generate exact executable and entrypoint paths. Merge the named entry into the host configuration; do not overwrite unrelated servers.

See the [installation guide](../../docs/install/antigravity.md). User testing confirmed v0.1.x CLI operation, including a v0.1.1 fresh-session replay with automatic activation for a complex task and execution-contract scope control. IDE execution is untested; see the guide for evidence boundaries.
